# 할 일 CLI

터미널에서 쓰는 할 일 관리 도구. Node.js로 만들고, 실행에 외부 패키지를 쓰지 않는다. 리눅스·맥·윈도우에서 똑같이 동작해야 한다.

- `todo add "우유 사기"`로 할 일을 더한다. `--due 2026-10-15`로 마감일을, `--tag 집`으로 태그를 붙일 수 있다(태그는 여러 개).
- `todo list`는 끝나지 않은 일을 마감이 가까운 순으로 번호와 함께 보여 준다. 마감이 지난 일은 「밀림」으로 표시한다. `--all`이면 끝난 일도, `--tag 집`이면 그 태그만.
- `todo done <번호>`로 끝내고, `todo undo <번호>`로 되돌린다. 번호는 `todo list`에 보이는 번호다.
- `todo edit <번호> "새 제목"`으로 고치고, `todo rm <번호>`로 지운다.
- `todo search <낱말>`은 제목에서 찾는다(대소문자 무시, 한글 포함).
- `todo export todos.csv`로 내보내고 `todo import todos.csv`로 들여온다. 엑셀에서 열 수 있어야 한다.
- `todo stats`는 이번 주에 끝낸 수, 남은 수, 밀린 수를 보여 준다.
- 기록은 현재 폴더의 `todo.json` 하나에 쌓인다. 파일이 깨져 있으면 덮어쓰지 말고 무엇이 문제인지 말한다.
- 잘못된 입력(없는 번호, 없는 날짜 등)은 이유를 한 줄로 말하고 0이 아닌 코드로 끝난다.
