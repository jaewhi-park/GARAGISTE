# 중복 파일 찾기

터미널에서 쓰는 중복 파일 찾기 도구. Go로 만들고, 표준 라이브러리만 쓴다.

- `dupfind <폴더>`로 그 폴더 아래(하위 폴더 포함)에서 내용이 똑같은 파일들을 묶어 보여 준다. 묶음마다 파일 하나의 크기와 경로들이 나오고, 낭비가 큰 묶음(크기 × (개수 − 1))부터 나온다.
- 크기가 0인 파일은 세지 않는다. `--min-size 1M`처럼 이보다 작은 파일은 건너뛸 수 있다(단위 K·M·G).
- `--json`이면 같은 결과를 JSON으로 낸다.
- 읽을 수 없는 파일·폴더가 있으면 그 경로를 경고로 알리고 나머지는 계속 본다. 심볼릭 링크는 따라가지 않는다.
- 파일을 지우거나 바꾸지 않는다.
