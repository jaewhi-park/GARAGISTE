# 웹 메모장

브라우저에서 쓰는 작은 메모장. Node.js로 만들고, 외부 웹 프레임워크와 외부 서비스는 쓰지 않는다.

- `npm start`로 로컬 서버를 띄운다(기본 포트 3000, PORT 환경 변수로 바꿀 수 있다). 브라우저로 열면 메모 목록이 보인다.
- 입력창에 쓰고 「저장」을 누르면 목록 맨 위에 추가된다. 빈 메모는 저장하지 않는다.
- 메모 옆 「삭제」로 지울 수 있다.
- 메모는 서버의 `data/memos.json`에 저장되고, 서버를 다시 켜도 남는다.
- 실제 브라우저에서 「저장 → 새로고침 → 그대로 있음」이 확인돼야 한다.
