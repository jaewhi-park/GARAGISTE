# 작은 도서관 대출 관리

아파트 작은 도서관의 대출 업무를 하는 웹 앱. 봉사자들이 사무실 PC 한 대의 브라우저로 쓴다. Python으로 만들고, 실행에 외부 패키지와 외부 서비스를 쓰지 않는다. 리눅스·윈도우에서 똑같이 동작해야 한다.

- 명령 한 줄로 서버를 띄우고 브라우저로 연다(기본 포트 8000). 옵션으로 포트와 데이터 파일 위치를 바꿀 수 있다(기본은 현재 폴더의 `library.db`). 회원 연락처가 들어 있으니 다른 PC에서는 열리지 않아야 한다.
- 책을 등록한다: 제목, 저자, 등록번호. 같은 책이 두 권이면 등록번호도 둘이다. 이미 있는 등록번호는 받지 않는다.
- 제목이나 저자의 일부로 책을 찾는다(대소문자 무시, 한글 포함). 권마다 빌릴 수 있는지, 나가 있으면 반납 예정일을 보여 준다.
- 회원을 등록한다: 이름, 연락처. 회원 번호는 앱이 붙인다. 회원 화면에서 지금 빌린 책과 지난 대출 기록을 본다.
- 회원 번호와 등록번호로 빌려준다. 기간은 14일이고, 반납 예정일이 휴관일(월요일)이면 화요일로 미룬다. 한 사람이 동시에 5권까지. 이미 나간 책, 없는 회원·책은 이유를 보여 주고 빌려주지 않는다.
- 등록번호로 반납받는다. 늦게 들어오면 며칠 늦었는지 보여 주고, 늦은 날수만큼 그 회원은 새로 빌릴 수 없다(회원 화면에 언제까지인지 나온다).
- 대출 중인 책은 한 번, 7일 연장할 수 있다.
- 연체 목록은 반납 예정일이 지난 대출을 오래 밀린 순으로, 회원 이름·연락처와 함께 보여 준다.
- 대출 중인 책은 예약할 수 있다(여럿이면 먼저 한 순서). 반납될 때 「○○님 예약」이라고 알리고, 사흘 동안은 그 회원에게만 빌려준다.
- 책 목록과 대출 기록을 CSV로 내려받는다. 엑셀에서 열어도 한글이 깨지지 않아야 한다.
- 백업 버튼을 누르면 `backups/` 폴더에 날짜·시각이 이름에 든 사본이 생긴다. 서버를 끈 채 명령으로 백업을 되살린다 — 되살리기 전의 데이터는 덮지 말고 따로 남긴다.
- 새 버전으로 바꿔도 쓰던 데이터 파일을 그대로 연다. 데이터 파일이 망가져 있으면 새로 만들어 덮지 말고, 무엇이 문제인지 말하고 멈춘다.
- 잘못된 입력은 화면에 이유를 한 줄로 보여 준다.

먼저 필요한 것은 책·회원 등록, 대출·반납·연장, 연체 목록, 백업이다. 예약과 CSV는 그 다음이어도 된다.
